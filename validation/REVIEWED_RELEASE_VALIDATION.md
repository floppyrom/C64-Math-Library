# Reviewed release validation

This release combines baseline evidence with fresh validation of the all-native-signed refresh.

1. **Prior exhaustive baseline evidence.** `baseline_prior_final/GAME_MATH_VALIDATION_FINAL.json`, `baseline_prior_final/GAME_MATH_ACCURACY_FINAL.json` and `baseline_prior_final/GAME_MATH_INTEGRATION_AUDIT_FINAL.json` remain evidence for unchanged library functionality. The native-signed refresh intentionally changes signed multiply/divide executable paths, so those paths are revalidated independently below rather than being covered by the older binary-delta argument.
2. **Fast ISQRT32 evidence.** `review/ISQRT32_FAST_VALIDATION.json` runs 5,097 boundary, perfect-square-neighbourhood and deterministic-random cases per profile, checks the exact root, input preservation and carry contract. `review/ISQRT32_FAST_PERFORMANCE_4130.json` remeasures the same 4,130-case performance corpus used in the prior table. `review/ISQRT32_FAST_DELTA_AUDIT.json` still verifies the documented ISQRT32 optimization ranges.
3. **Source-relocation evidence.** `source_relocation/ALTERNATE_MAP_VALIDATION.json` executes all 45 public entries at a deliberately different assembly-time map: 4,172 calls per profile, 16,688 total. `source_relocation/DETERMINISTIC_REBUILD.json` proves clean rebuild identity for all reference/alternate PRGs and generated REU images; `CONFIG_VALIDATION.json` records 27 accepted/rejected configuration cases.
4. **Assembler/Turbo evidence.** `turbo_relocation/TURBO_RELOCATION_VALIDATION.json` exercises V3/V4 Turbo16/Turbo32 BEGIN/CALL/END in reference and relocated layouts: 17,164 product calls plus 32 BEGIN/END lifecycle calls (17,196 Turbo API calls total), exact ZP restoration, second-batch reuse, moved overlay REU banks and cycle-vector identity. `turbo_relocation/TURBO_BOUNDARY_SWEEP.json` adds 3,556 exact products at the minimum/maximum supported ZP origins and high REU-bank endpoints. The historical pre-native ACME pass is retained as `acme/ACME_SOURCE_BUILD_VALIDATION_PRE_NATIVE.json`. A current ACME rerun is recorded as `NOT_RUN` in `acme/ACME_SOURCE_BUILD_VALIDATION.json` because the validation container has no ACME executable and no outbound package/network access; `tools/verify_with_acme.py` remains the reproducible command to rerun it when ACME is available.
5. **V5 Hybrid Low-ZP evidence.** `hybrid/HYBRID_VALIDATION.json` validates the fixed 31-byte-ZP hybrid on reference and alternate maps, including 45/45 stable entries, direct V2 import parity, exhaustive UMOD8, cold-load optional-init behavior and ZP confinement. Its config and deterministic-rebuild files cover rejected maps and repeat identity.
6. **Custom Pareto Builder evidence.** `pareto/PARETO_SELECTOR_VALIDATION.json` covers six resource breakpoints on both reference and alternate maps: 12 generated builds × 4,172 calls = **50,064 common-API machine calls**. It also records **10,108 direct V2 cycle-parity cases**, exhaustive **65,536-case UMOD8**, V1/V5 byte-identity endpoints, exact RAM accounting and ZP confinement. `pareto/PARETO_CONFIG_VALIDATION.json` adds **12/12** resource/map acceptance/rejection checks. `pareto/PARETO_STRESS.json` adds **50,144 SMUL16 cycle-parity cases**, **25,000 mixed-workload iterations** and **10,000 ZP-guard iterations**.
7. **Native-signed ownership evidence.** `review/SIGNED_LAYOUT_VALIDATION.json` performs **279 structural checks** and traces 13 signed/unsigned API pairs across all V1–V5 profiles. All **65 comparisons have zero executable-instruction overlap** after initialization. Immutable lookup tables may still be shared, but no signed API enters its corresponding unsigned executable engine.
8. **Published signed-source evidence.** Every native `SMUL*`/`SDIV*` entry now has an exact per-routine executable source mirror under the profile `resident/signed/{multiply,division}/native/` tree. `review/PUBLISHED_SIGNED_SOURCES_VALIDATION.json` verifies **65 published routines / 270 checks** against the initialized resident bytes.
9. **Native-signed arithmetic evidence.** `review/SIGNED_MULTIPLY_VALIDATION.json` executes **264,999 signed multiply calls** with zero errors, including exhaustive signed 8×8 coverage for independent implementation families and wide edge/random products. `review/SIGNED_DIVISION_VALIDATION.json` executes **364,533 signed divide/modulo calls** with zero errors, including exhaustive SDIV8 coverage, wide signed cases, zero divisors, aliases and fixed-point division. Profile-partitioned runs use the global profile index for deterministic RNG seeds, so split and unsplit runs use the same corpus.
10. **Native-signed performance delta.** `review/NATIVE_SIGNED_DELTA_AUDIT.json` compares the immediate pre-refresh signed-taxonomy package with this release on identical corpora. Newly split/compacted multiplier paths improve by **3 cycles** on average exactly; the already-native V2–V4 SMUL16 is unchanged. The newly private `SDIV32_32` is also faster on all five profiles. Resident PRG sizes/load-end ranges are unchanged.

The integrated `tools/release_audit.py` cross-checks these evidence files against the current generated binaries. When ACME is unavailable it reports `PASS_WITH_ACME_NOT_RUN` rather than treating historical ACME hashes as current evidence.
