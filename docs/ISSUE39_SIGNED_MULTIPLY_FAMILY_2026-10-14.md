**Date:** 14 October 2026. **Scope:** the five resident public profiles, SMUL8, SMUL16, SMUL24, SMUL32 and SMUL32_READY. Separate shifted-result SMUL16_SHR8/SMUL32_SHR16 and REU Turbo/QS families retain their later Issue #39 campaign steps. Private OptiSearch files remain unpublished.

## Exact evidence, comparison safeguards

The baseline `validation/review/SIGNED_MULTIPLY_VALIDATION.json` contains **264,999** 6502 public calls. The independent new gate `tools/issue39_signed_multiply_family_audit.py` checks exact signed products, carry C=0, preserved operands, stack balance, and public-cycle vectors on common five-profile corpora: exhaustive SMUL8 (65,536 pairs each), signed 16-bit (4,457), signed 24-bit (2,409) and signed 32-bit (2,409), then pairs normal SMUL32 with SMUL32_READY on the same 2,409 operands. A bounded V1/V5 mixed-call READY pointer-state screen independently checks normal entry correctness. Native VICE is a separate installed-resident correctness test; **no native cycle timings are claimed**.

Only *same-input, same-model, same-ABI* vectors support runtime gain claims. The original `validate_signed_multiply.py` uses profile-specific signed operand seeds, so its sub-cycle differences between V2/V3/V4 must not be called hardware/profile penalties. The private OptiSearch record timings above have different entry, resource, operand and/or table contracts; a raw native-vs-public subtraction is meaningless.

### Stable release acceptance

1. No shipped resident byte or public ABI change and no ZP/stack/table growth unless a superior **compatible** implementation is fully qualified.
2. Reference and alternate source maps, standalone source access, profile selectors, standard signed/unsigned suite, mixed calls, native x64sc and checksummed package remain qualified.
3. Publish a no-gain result where a credible donor idea lacks public-ABI matched correctness/resource/timing evidence. Do not invent a better replacement from speculative table algebra.
4. Final premerge tests and **postmerge main** full-library, comparable-performance and new signed-family checks must all pass before marking the **signed multiply** checkbox in Issue #39. **Do not close Issue #39.**
