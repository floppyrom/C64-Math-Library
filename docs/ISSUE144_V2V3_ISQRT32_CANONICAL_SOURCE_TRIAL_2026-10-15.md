# Issue 144 - V2/V3 ISQRT32 normal-resident source integration

**Source-only trial, 15 October 2026.** The independently qualified direct-highword seed fits the original 192-byte normal resident V2/V3 root slot (REG_GAME + $0A40 to + $0AFF), including reference and alternate memory maps. Ordinary public MATH_ISQRT32 entry, input N, output MATH_Z, carry, X/Y/SP and normal zero-page budgets remain unchanged; no application-owned RAM or new REU bank is required.

**Evidence:** [research PR 174](https://github.com/floppyrom/C64-Math-Library/pull/174) passed 26/26 workflows. In paired source-built tests, 3,388 unrestricted 32-bit input pairs showed exactly 47 modeled CPU cycles saved on every input; 192 native x64sc calls matched across V2/V3 reference and alternate layouts, with a real 512-KiB REU for V3. The separate source-integration [workflow #38803287111](https://github.com/floppyrom/C64-Math-Library/actions/runs/38803287111) passed generator owner check, paired source/model, native VICE and all 56 public API source assembly checks for both maps.

**Caveat:** The legacy whole-file source generator reads frozen historical reference PRGs and currently rewrites unrelated previously optimized canonical source sections. The new normal-root final-owner declaration is reproducibly generated in temporary output and normal current source builds pass, but global byte-for-byte source regeneration still needs reconciliation. Historical reference PRGs/REUs and published performance records are not regenerated. Physical VIC/REU DMA timing, IRQ/NMI concurrency and broader multi-API stress need separate validation. Private OptiSearch implementation is excluded.
