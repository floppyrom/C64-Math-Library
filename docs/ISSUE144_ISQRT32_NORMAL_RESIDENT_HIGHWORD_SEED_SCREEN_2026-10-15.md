# Issue #144 C — V2/V3 unrestricted ISQRT32 normal-resident source screen

**Research branch, not a production change.** Independently qualified direct-highword seed from PR #155 previously saved 47 modeled cycles on every tested V2/V3 32-bit radicand, but used caller-owned $0C00 RAM. This new screen tries to fit the **same producer** in the canonical pre-existing normal resident $CB40..$CC00 source slot.

The source transformer translates hardcoded table/ZP/IO/CPU addresses to the canonical source relocation symbols and places the self-contained main at `REG_GAME+$0A40` and highword seed helper at `REG_GAME+$0AD0`. Both the V2 and V3 source trees are assembled **in memory** for reference and alternate memory maps. It asserts that the only image changes lie within the original 192-byte root region; checks the unchanged ordinary `MATH_ISQRT32` trampoline and no additional normal zero page or caller RAM; compares public-entry CPU calls on identical 32-bit radicands to `math.isqrt`, including input preservation, carry, X/Y and SP.

Results must be published from actual CI, not projected. A green CPU-model screen is only a feasibility checkpoint. Full 56-entry mixed-call qualification, actual x64sc (V3 with correct REU), native physical memory collision, release/payload publication and native cycle timing remain required. Do not install into normal source or update production PERFORMANCE until they pass. Private OptiSearch materials excluded.

## Completed independent qualification (15 October 2026)

Source-built GitHub Actions [run #38800596919](https://github.com/floppyrom/C64-Math-Library/actions/runs/38800596919) **PASS** at the first research head. Across V2 and V3, both reference/alternate layouts, there were **847 distinct unrestricted 32-bit radicands each** (**3,388 same-input baseline/candidate comparisons; 6,776 public CPU-model executions**). Every correct pair saved exactly **47 model cycles**, with no slower input, zero added normal ZP/caller RAM, preserved public ISQRT32 trampoline, and all changed bytes confined to the existing 192-byte normal resident slot. No public binary files changed.

Independent real x64sc [native workflow on commit ac28f303](https://github.com/floppyrom/C64-Math-Library/commit/ac28f30385e9140465a676fb96c490d4be22fd51) **PASS**: **192 native calls** (24 old plus 24 candidate, V2/V3 and reference/alternate layouts). Captured root and full status bytes are identical on every paired case; genuine V3 512-KiB REU enabled. This is correctness evidence, **not** physical bus-time cycle measurement. The alternate V3 REU image is the historical bank layout, so this does not qualify unrelated bank-relocated REU APIs.

**Decision:** qualified independent normal-resident source candidate, not default integration. Next steps are to stage canonical source-generator ownership (the monolithic source is regenerated from frozen binaries), validate the entire 56-entry mixed-call ABI, normal memory/resource maps and interrupts, rerun native and package gates, then promote source-only if successful. Do not update `PERFORMANCE.md` or repackage reference images based on this opt-in evidence alone.
