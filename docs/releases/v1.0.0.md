# C64 Math Library v1.0.0 — Operation-First Edition

**First supported release of the operation-first C64 Math Library.** This
version number refers to the new project release, **not** the archived
historical `V1 Balanced` resident profile.

Build just the mathematical routines your program uses, under your own
memory and zero-page limits. The installer produces a real C64 PRG, its
matching public API include, and an exact memory/source manifest.

## Highlights

- **56 independently linkable stock-C64 public operations:** signed and
  unsigned 8/16/24/32-bit multiplication, division and remainder,
  shifted/fused arithmetic, integer square roots, reciprocal, 8-bit
  trigonometry, ATAN2, distance, 2D vector normalization, and eight-slot
  movement/SEEK services.
- **One operation-first setup:** `make builder-setup` or
  `python3 tools/configure_math.py`. No V1–V5 profile selection.
- **Four optimization goals:** `balanced`, `speed`, `size`, `zp`.
  Speed uses real per-operation call-frequency weights and comparable
  variant input corpora; all modes obey the stated memory constraints.
- **Exact build outputs:** `math_selective.prg`, `math_api.inc` and
  `selective_manifest.json` report the selected implementations,
  their public entry addresses and combined physical RAM/ZP footprint.
- **Published performance and resource evidence:** a 56-operation
  per-routine cycle/RAM/ZP/stack reference and 122 separately measured
  selectable source-variant observations, with SHA-qualified provenance.
- **Optional REU hardware companions:** source-built Turbo16
  (unsigned 16×16→32), Turbo32 (unsigned 32×32→64) and QS16
  (unsigned 16×16→32 using an REU quarter-square table).
  They require an explicitly selected REU, one service at a time,
  their own loadable PRG and successful hardware INSTALL.
- **Historical preservation:** old V1–V5 residents and their REU images
  remain in the repository as compatibility/test references, not as
  the recommended setup for new projects.

## Start here

Requirements: Python 3.12 or later and Make. Clone or download the
**GitHub-generated source archive attached to this release**; it contains
the installer and independently assembled sources. There is deliberately
no one-size-fits-all `math.prg`: each user generates their own PRG with
the requested operations and memory placement.

```sh
make builder-setup
```

For an unattended example:

```sh
python3 tools/configure_math.py \
  --operation UMUL16 --operation UDIV16 --operation ISQRT16 \
  --objective balanced --ram-budget 4096 --zp-budget 8 \
  --config-out example-math.json --build-dir example-math-build
```

Load `example-math-build/math_selective.prg` and use the **matching**
`example-math-build/math_api.inc`. Do not hardcode historical
resident addresses. The `selective_manifest.json` reports actual
combined memory ownership; isolated routine sizes must not be summed.

Existing checked-in configuration:
`examples/operation-first.json`. For the complete workflow consult
[README](../../README.md), [Quick Start](../../QUICK_START.md),
[API contract](../API_COMPATIBILITY.md), and
[resource/cycle measurements](../OPERATION_FIRST_ROUTINE_METRICS.md).

## REU options and their scope

Turbo16 and Turbo32 DMA-SWAP executable zero-page overlays into the C64;
QS16 generates and stores a large quarter-square table in REU RAM and
DMA-reads two entries per multiply. **The REU is not a math coprocessor.**
All three are explicit hardware services with separate INSTALL, BEGIN,
CALL, END entry points and a stock-C64 fallback. Their resource costs,
hardware requirements, and instructions are in the
[REU integration guide](../REU_OPERATION_FIRST_CONSOLIDATION.md).

They are **opt-in advanced features**. Real hardware, unrestricted
IRQ/VIC/SID concurrency, nested calls, per-call DMA-inclusive speedups
and sustained 25/50 fps application deadlines are **not guaranteed**.

## Evidence and known limitations

- All 56 operations have selectable source-built stock-C64
  implementations and source-qualified CPU-model performance evidence.
  The builder, public ABI, exact memory reservations and generated
  package are covered by dedicated release-acceptance regression tests
  and native-VICE source qualification in the repository.
- Individual measured means are *not* guaranteed PAL frame times;
  the user's actual combined PRG and use pattern determine memory use
  and performance. See [PERFORMANCE.md](../../PERFORMANCE.md).
- The math library is **non-reentrant**. Respect live ZP, scratch,
  persistent state, initialization, and IRQ conflicts.
- `speed` minimizes modeled cycles under the declared workloads and
  budgets. **Full fastest-historical-source parity is not yet
  certified** (tracked in
  [#375](https://github.com/floppyrom/C64-Math-Library/issues/375)).
  Further specialized optimization remains optional
  ([#144](https://github.com/floppyrom/C64-Math-Library/issues/144)).
- The **1541/1571/1581 do not yet have executable operation-first
  backends**. This release targets the stock C64, with optional
  C64-side REU services.
