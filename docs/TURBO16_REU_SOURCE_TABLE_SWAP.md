# Turbo16 CPU-model REU SWAP with source-backed lookup tables

This experiment combines three separately source-qualified components without shipping a user-installable REU service: the 122-byte executable zero-page Turbo16 multiplier overlay and 21-byte public CALL binder; the REU DMA SWAP controller (command $92) implementing guarded BEGIN, CALL and END; and four 512-byte quarter-square planes materialized from both checksum-locked V3 and V4 relocatable ASM sources, **not** extracted from archived PRGs during the test.

The two historical source tiers must supply identical bytes. A 224-call two-batch deterministic arithmetic replay executes at two different memory layouts and on both the 512-KiB and 16-MiB modeled REU tiers. It verifies products, Carry, input and stack preservation, no nested BEGIN, and byte-for-byte restoration of all 122 bytes of caller zero page after END. The overlay in REU intentionally retains its self-modified operand bytes between batches: DMA SWAP exchanges the **current** executable overlay, not an immutable copy of its initial image.

Run the source-backed proof:

~~~sh
python3 -m unittest discover -s tools -p 'test_reu_turbo16_source_tables.py' -v
python3 -m unittest discover -s tools -p 'test_reu_turbo16_swap_experiment.py' -v
python3 tools/reu_turbo16_swap_experiment.py --out build/reu-source-swap
~~~

**Not established by these tests:** the tables are materialized from original verified source literals, not independently generated by a formula. A real C64+REU installation is not yet emitted. The controller does not yet probe REU presence, upload the overlay or tables to a chosen REU bank, reserve all user RAM/ZP/REU regions in the operation-first allocator, or establish asynchronous VIC/IRQ safety. The CPU model's DMA cost is not a measured native 1750 bus-stall timing result.

The operation-first installer therefore must **not** offer a native REU variant on the strength of this experiment alone. It still emits stock-C64 source-qualified arithmetic. Separate V3/V4 REU compatibility bundles remain available unchanged.

Next: build a source-qualified complete PRG/REU payload loader and explicit hardware-detection/error path, integrate bank and overlay reservations into the global selector, then qualify pinned native-VICE REU DMA and the complete historical public-call corpus. Only after these passes can a hardware-REU mode become user-selectable.
