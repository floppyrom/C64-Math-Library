# Issue #144 C — V5 inherited V1 normal-resident ISQRT32 (15 October 2026)

**Source-generated research proof only; not a default V1/V5 resident promotion or reference binary update.** [V1 parent PR #178](https://github.com/floppyrom/C64-Math-Library/pull/178) is merged and independently qualified. This experiment builds the actual V5 reference and alternate hybrid sources and applies the independently assembled V1 root patch **in memory** at original V1 `REG_GAME+$0A40` through `+$0ADF`; it proves every V5 resident byte in that interval matches the baseline V1 source, including the unused seed-helper placement at `REG_GAME+$0AA8`.

[Exact source-model CI](https://github.com/floppyrom/C64-Math-Library/actions/runs/38809949084) passed **1,329 paired unrestricted 32-bit root calls per relocation map (2,658 total)**. Savings were **exactly 51 modeled NMOS-6510 CPU cycles on every pair** (mean/min/p95/max 51), zero regressions. The test also passed **36 sequential ISQRT16/ISQRT32 interleaving smokes per map**, 92 changed resident bytes, correct integer roots, output carry, preserved inputs, X/Y and stack; **no new normal-ZP bytes or caller RAM**. The V5 normal-footprint source loader and public root trampoline were unchanged. V5's private imported routines were not altered.

[Exact native VICE run](https://github.com/floppyrom/C64-Math-Library/actions/runs/38810124166) passed **96 paired original/candidate x64sc public root calls total**, 48 for each memory layout, with identical captured result/status bytes, under SHA256-pinned VICE 3.10+r46274. These are **root-only** native calls: the V5 alternate imported code at $E000 is not within the root harness's serialized PRG range, so this does **not** qualify every imported V5 kernel or any full mixed-call workload. No physical VIC/REU/DMA wall-cycle timing was measured.
