# Native signed implementation reference

The canonical executable source for V1–V4 is `relocatable_source/<profile>/math_relocatable.asm`; V5 is generated by `tools/build_hybrid.py` from the V1 base. Per-profile `resident/signed/SIGNED_LINK_MAP.json` files record native signed entry points and private-core placements.

## Per-routine published source

Every shipped signed multiply/divide API now has a directly browsable, exact executable source mirror in the profile tree:

- `resident/signed/multiply/native/*.asm` for `SMUL8/16/24/32`, `SMUL32_READY`, `SMUL16_SHR8`, and `SMUL32_SHR16`.
- `resident/signed/division/native/*.asm` for `SDIV8/16/24/32_16/32_32` and `SDIV16_SHL8`.

The mirrors are generated from the initialized resident image, contain every reachable executable instruction for that signed API, and annotate every instruction with its exact address and bytes. `tools/validate_published_signed_sources.py` proves the publication view matches the shipped executable byte-for-byte. They are audit/source-publication views; the integrated relocatable source remains the build authority.

For V2–V4 the hand-authored executable-ZP `SMUL16` source (`smul16_practical_116zp.a`) and relocation description are retained alongside the exact runtime mirror. Existing historical/reference divider `.a` files are also retained where useful.

Private wide multiply and `SDIV32_32` kernels are placed in pre-existing unused/reserved address holes. This preserves public ABI addresses, normal ZP allocation, and PRG load/end boundaries. Immutable lookup tables may be shared without weakening the executable-independence requirement.
