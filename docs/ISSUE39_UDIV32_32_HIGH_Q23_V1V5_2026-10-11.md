# Issue #39: V1/V5 bounded 32-bit quotient-two/three fast path

**Date:** 2026-10-11. **Status:** source candidate under PR #56; full release and independent CI required before merging.

## Proof and implementation
The previous early gate proves divisor nonzero and numerator greater than divisor. PR #54 already intercepts conservatively proven quotient-one cases. The new gate only handles divisor high byte $40–$7F and numerator high byte strictly greater than twice that byte **plus one**. The plus-one allowance covers the carry from doubling the divisor's lower 24 bits. Thus N≥2D, and D≥2^30 implies 4D≥2^32>N: the quotient must be 2 or 3.

An additional 131-byte source island at `REG_TABLE+$0860…+$08E2` subtracts D twice into the public R output, conditionally subtracts it a third time, and returns exact Q and R with carry clear. The counter uses DEY rather than CPX, because CPX would overwrite carry in a multi-byte SBC chain (an earlier discarded prototype had this defect). Nonqualifying cases jump to the original restoring divider. No normal ZP growth, no public API relocation, no resident PRG span growth, and no new REU/tables.

## Same-input performance

| Public entry | PR #54 baseline | Candidate | Mean change |
|---|---:|---:|---:|
| UDIV32_32, 2,729 pairs/profile | 370.572004 | **359.077684** cycles | 3.10% faster |
| UMOD32_32, 1,705 pairs/profile | 444.652199 | **436.899707** cycles | 1.74% faster |

Paired V1 calls: UDIV 102 faster / 633 slower / 1,994 equal; UMOD 49 faster / 453 slower / 1,203 equal. Largest speedup 388 cycles, maximum slowdown 22 cycles. There were zero result/carry/input mismatches. V5 inherits exactly the same source and cycle vectors.

A separate independent 4,000-case benchmark per scenario found **uniform 32×32** improved 265.475→244.034 cycles; **large divisors $40–$7F high byte** improved 261.252→163.469; targeted q=2/3 improved 690.371→315.764; divisors with top bit set were unchanged; **small divisors under 2^24** regressed 1542.874→1554.841. This is an explicit mean-speed/latency Pareto trade-off, not universal dominance. All rankings remain input-distribution-specific and use identical operands across profiles.
